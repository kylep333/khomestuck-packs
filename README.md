# khomestuck-packs

Section packs for **kHomestuck**, a KOReader plugin that reads Homestuck on jailbroken Kindles
page by page, with animated panels and [S] animations (sound over Bluetooth via KinAMP).

The plugin downloads these itself; you don't need to fetch anything here by hand.

- `index.json`: every act and intermission, with page ranges and pack sizes
- `<section>.zip`: one pack per act or intermission

The packs are converted from the Unofficial Homestuck Collection asset pack: grayscale panels,
dithered animation frames and the original audio, for e-ink.
